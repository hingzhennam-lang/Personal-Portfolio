# Hing Zhen Nam — Personal Portfolio

A responsive personal portfolio built with HTML, CSS and vanilla JavaScript.

## Files

- `index.html` — portfolio content and page structure
- `style.css` — responsive styles
- `script.js` — mobile navigation and reveal effects

## Local preview

Open `index.html` in your browser, or open this folder in Visual Studio Code and use the Live Server extension.

## GitHub Pages

In the repository settings, open Pages and select deployment from the `main` branch and the root folder.
